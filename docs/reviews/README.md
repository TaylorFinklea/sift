# Review receipts

These files record independent model reviews, verification runs and production release checks for Sift. [`review-summary.md`](review-summary.md) is the best place to start.

Before the repository was made public, the author's hostnames, Cloudflare account, zone, D1, Access and domain-binding IDs, the Access team name, an iCloud container identifier and workstation paths were replaced with placeholders such as `sift.example.com`, `<redacted-account-id>` and `~`. Any hash that covers redacted text will no longer match.
