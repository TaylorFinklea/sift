Sift

Privacy

Effective November 9, 2026. Sift helps you organize cards and record sorting decisions. This notice describes the website and iPhone app.

Website data and access

Collections, card details, sort plans, and sort history you add on the website are stored in a Cloudflare D1 database. Access to the main website is restricted through Cloudflare Access. Cloudflare Access processes the identity used to sign in so the site can check whether access is allowed. Website and API requests pass through Cloudflare, which may process technical connection and security information to provide and protect the service.

Website analytics

The website uses Cloudflare Web Analytics, which loads a Cloudflare analytics beacon to measure page views and performance using the browser Performance API. Cloudflare states that Web Analytics does not collect or use visitors' personal data. See Cloudflare Web Analytics and Cloudflare's privacy policy for details about Cloudflare's service and data practices.

iPhone app and iCloud

The iPhone app stores a local copy of its library on the device. When sync is enabled, Sift also uses CloudKit's private database in your iCloud account. This is separate from the website's D1 database. Apple says a private CloudKit database is accessible only to that iCloud account by default, and its data counts toward the account's iCloud storage. See Apple's CloudKit private database documentation and Apple's privacy policy. Website and iPhone libraries are separate; use Sift's export and import features to transfer a library between them.

Retention and removal

Sift does not set an automatic expiration schedule for its library data or provide a user-accessible library erasure feature. Website collections and sort history are stored in the website database; the iPhone app stores a local copy and, when sync is enabled, records in the private CloudKit database. Sift currently provides no in-app deletion flow for those library records. Exported Sift files are copies saved where you choose; you manage those files separately from the library in Sift. Cloudflare and Apple process service and account information under their own policies.

Use and transfer

Library content is used to provide Sift's collection, sorting, history, and transfer features. You can export a library to a file and import it into the separate website or iPhone library. Keep exported files in a place you control.

Questions

For help and updates, see Sift Support. This notice may be updated as Sift's features or data practices change.
