Quick help for common Sift tasks.

Move a collection between the website and iPhone

Open a collection or your library and choose Export. On the other device, use Import and select the exported Sift file. Review the import preview before adding it to that library.

Continue sorting offline

The iPhone app keeps a local library for offline use. Private iCloud sync can keep Apple devices in sync when iCloud is available.

The website asks me to sign in

The website is protected by its access proxy. Sign in with the account authorized for this private Sift instance.
